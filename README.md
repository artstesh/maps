# @artstesh/maps

Let's map a feature ;)

### Description of the project

The main purpose of the project is to make easier the process of using of [openlayers library](https://openlayers.org/) in Angular projects.

### Support status

This line targets Angular 14, which is end-of-life, and is **archived**: it receives no
further features, fixes, ports, or releases. Migrate to a supported Angular major and
install the matching `@artstesh/maps` line - see the version support table at
https://maps.artstesh.ru.
